# 2026-11-22 · 浏览 5 秒回跟随时变成瞬移

## 现象

手动翻动歌词后静止 5 秒，回到当前播放行时没有动画，直接瞬移。

## 根因

`startFollow` 一开始就把滚动模式切成 `Follow`，之后才快照“每行当前屏幕位置”：
此时 `currentScroll()` 已经按旧的锚点行计算，而不是浏览时的真实位置，快照到的起点是错的 → 过渡从错误位置开始，看起来就是瞬移。
另外“同目标不重启”的短路条件没有限制必须已处于 `Follow`，浏览态下也会被吞掉。

## 修复

- 先用当前状态（浏览/过渡/跟随）快照每行屏幕 Y，再切到 `Follow` 启动过渡；
- “同目标不重启”条件加上 `scrollMode == Follow`。
