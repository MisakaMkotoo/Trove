# 2026-11-22 · 首行歌词顶进虚化区；三连点实际渲染过大

## 现象

1. 歌词第一行（以及开唱前的三连点行）总是贴在最顶端，半截落在顶部渐隐/虚化区里；从第二行开始才在正常播放位。
2. 三连点按“字号放大 1.25 倍”实现后，视觉直径远大于原 6dp 小点的 3 倍（看起来像半径放大 5–6 倍）。

## 根因

1. 焦点定位把当前行顶部放在 `focusY = 行高 + 10dp`，但首行的目标滚动量是负数，被 `clampScroll` 钳到 0 —— 首行因此停在 y=0，而其他行有足够的正向滚动空间，能停在 focusY。
2. 圆点是用 “●” 字形渲染的，字形直径接近字号本身；headline 字号 ×1.25 ≈ 35sp，实际直径约 30dp，远大于原 6dp 点的 3 倍。

## 修复

1. 歌词内容顶部加一个等于 `focusScreenY(0)` 的空区 `topInsetPx`：
   - `prefixTop` 与 `maxScroll` 都计入该空区，布局放置时 `y = topInset + prefix - scroll`；
   - 首行目标滚动量变为 0，正好停在正常焦点高度，不再进入虚化区。
2. 三连点字号系数从 1.25 改为 0.8（约 22sp），视觉直径贴近原小点的 3 倍。
3. 首行焦点高度按“上一行是普通行还是三连点行”取对应行高，三连点之后的第一行自然下移到正常位置。

## 状态

已修（2026-11-22）。
